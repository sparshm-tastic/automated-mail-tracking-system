# Automated India Post Office Mail Monitoring System

## About the Project
This project is an automated mail tracking and monitoring system developed to streamline operations for a post office. It connects Google Forms to Google Sheets, using custom scripts to process and monitor mail data in real-time. 

*Note: This is a sanitized version of the project. All government URLs, sheet IDs, and sensitive information have been replaced with placeholder variables.*

## Tech Stack
* **Language:** JavaScript / Google Apps Script
* **Database:** Google Sheets
* **Input:** Google Forms

## Key Features
* Automated data entry from Forms to Sheets.
* Custom trigger functions to monitor incoming mail updates.
* Secure handling of tracking data.
